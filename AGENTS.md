# AGENTS.md

## Project

**Astraeon** — programmable trust & execution layer for autonomous AI agents on Rialo.

- Frontend: TanStack Start (React 19 + Vite) + Tailwind v4, TypeScript strict.
- Engine: `src/lib/astraeon/` — policy, risk, guard, credential gateway, Rialo transport, reputation.
- Rialo DevNet RPC is proxied server-side via `/api/rialo` (`src/server.ts`) because the node is HTTP-only without CORS.
- Deploy target: Vercel (`vercel.json`, nitro preset `vercel` → `.vercel/output`).

## Commands

```sh
npm run dev     # local dev server
npm test        # vitest test suite
npm run lint    # eslint
npm run build   # production build (nitro, vercel preset)
```

## Conventions

- Keep the working tree green: typecheck (`npx tsc --noEmit`), lint, tests, build all pass before committing.
- `src/routes/routeTree.gen.ts` is auto-generated by the TanStack Router plugin during dev/build — do not edit by hand; regenerate with a build.
- Never rewrite pushed git history (force push / rebase / amend / squash).
